# Glossary — Local Mineral Scanner-specific terminology

These per-language files (`German.md`, `French.md`, ...) hold everything about
a language's translation that is specific to Local Mineral Scanner: the coined
building name ("local mineral scanner") and how it sits against vanilla's
long-range mineral scanner, the "tuned to a mineral" phrasing, the twin-console
/ two-operator wording, the settings-window terms, the Workshop title, and any
mod-decided phrasing pending native review.

Family-shared, mod-independent findings — LanguageWorker mechanics, style and
corpus rules, and vanilla-grounded common vocabulary (research, roof, mass,
caravan, quality and stuff names, and so on) — live upstream in the `l10n/`
submodule at `l10n/languages/<Language>.md` (canonical checkout:
`~/dev/rimworld-l10n`), since they apply to any mod in the family.

When a translation pass coins a new mod-specific term, record it here. If a
pass instead surfaces a correction to shared mechanics or vocabulary, send that
fix upstream to the l10n repo rather than duplicating it here.
