# Contributing

Thanks for your interest in improving Local Mineral Scanner! Bug reports,
suggestions and pull requests are welcome. Build and development setup live
in CLAUDE.md.

## Localization

This mod does not ship translations yet. The mod will target the languages
below, chosen by RimWorld's per-language audience size, once translation work
starts. Contributions for any other language RimWorld supports will be
welcome too.

| Language             | Status  | Credit |
| -------------------- | ------- | ------ |
| English              | Source  | —      |
| Simplified Chinese   | Planned | —      |
| Russian              | Planned | —      |
| Korean               | Planned | —      |
| German               | Planned | —      |
| Spanish              | Planned | —      |
| French               | Planned | —      |
| Brazilian Portuguese | Planned | —      |
| Japanese             | Planned | —      |
| Traditional Chinese  | Planned | —      |

Statuses: **Source** (the authoritative English strings), **Machine-assisted**
(generated with terminology grounded against the official RimWorld
localization; awaiting native review), **Native** (written or reviewed by a
native speaker), **Planned** (not started — contributions welcome).

Once translation work starts, this file gains a "Contributing a translation"
section — see a released sibling mod (e.g. UniqueWeaponsUnbound) for the
format, and CLAUDE.md's localization section for the folder-gating rules
translations must follow.
