# Contributing

Bug reports, fixes, and features are welcome — open an issue or pull request.
Build instructions are in README.md; the mod builds with
`dotnet build LocalMineralScanner.sln -c Release`.

## Localization

This mod does not ship translations yet. Once it does, this file gains a
translation status table (language / status / credit) and a "Contributing a
translation" section — see a released sibling mod (e.g. UniqueWeaponsUnbound)
for the format, and CLAUDE.md's localization section for the folder-gating
rules translations must follow.

Statuses used by the ecosystem: **Source** (authored English), **Machine-assisted**
(model-drafted, human-reviewed), **Native** (native-speaker contributed or reviewed),
**Planned**.
